      How flows work
      
      
        
    • Start an edge label with a number to make it a step: A -->|1. Request| B
      • 
        
    • Edges without a number are always shown, as the static architecture.
      • 
        
    • Edges sharing a number play together: two 3. edges fan out at once.
      • 
        
    • Add narration with a comment: %% 3: Longer explanation
      • 
        
    • Click a box or arrow to see its details. Write them in the Details tab as YAML or JSON:
          types:            # optional, extends the built-in types
  service: { fields: [language, owner] }
nodes:
  API:
    type: service
    language: Go
    deploy: { platform: ECS, replicas: 3 }
edges:
  "2":              # a step number, or From->To
    method: POST
    endpoint: /orders
    headers: { Authorization: Bearer <token> }
    request: { body: { cartId: string } }
    response: { status: 201 }
      • 
        
    • Commit to save the diagram and details together as a new version. Use the back and forward buttons, the version dropdown, or the History tab to move between versions. Versions are kept in this browser.
      • 
        
    • Use the tool box beside the diagram to insert boxes and API calls. Inserted objects are locked: commits that change them are refused.
      • 
        
    • Built-in types: client, service, gateway, worker, database, cache, queue, external.
      • 
        
    • Space play or pause, ← → step, Home restart, F hide editor.
